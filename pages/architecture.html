04

Security Monitoring Workflow

How endpoint activity becomes security alerts in the SOC environment.

01

Endpoint Activity

Windows and Linux endpoints generate authentication events, process activity, system logs, and other security-relevant telemetry.

02

Wazuh Agent Collection

Wazuh agents collect configured endpoint events and forward supported security data to the Wazuh Manager.

03

Wazuh Manager Analysis

The Manager processes incoming events, applies decoders and detection rules, and generates alerts when configured detection conditions are met.

04

Indexing and Dashboard Visualization

Alert data is indexed by the Wazuh Indexer and presented through the Wazuh Dashboard for searching, monitoring, and investigation.

05

SOC Investigation and Response

The analyst reviews alert context, correlates relevant events, documents findings, and records appropriate response actions and investigation outcomes.
