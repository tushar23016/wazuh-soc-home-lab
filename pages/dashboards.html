ANALYST WORKFLOW

How to use the dashboard during triage

A repeatable workflow for moving from dashboard visibility to a documented investigation.

01

Check agent health

Confirm the relevant endpoint is enrolled and communicating. Note any disconnected or never-connected agent state.

02

Filter security alerts

Set a relevant time range and filter by severity, rule, agent, or event category. Record the query context.

03

Inspect event details

Review timestamp, rule ID, source fields, user, host, process details, and related events before drawing conclusions.

04

Document findings

Capture relevant evidence and link the investigation to the appropriate log-analysis, threat-detection, or incident record.
