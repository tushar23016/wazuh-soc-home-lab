REPORTING STANDARD

Evidence and quality checklist

Apply these checks before marking a report complete.

Analyst checklist

  • Include incident ID, author, review date, and reporting timezone.
  • Separate observed facts from hypotheses and analyst interpretation.
  • Reference source logs, alert IDs, hostnames, and query time ranges.
  • Record hashes for exported evidence where applicable.
  • Document response actions, authorization, and outcome.
  • State unresolved questions, limitations, and follow-up owners.

Reporting principles

Use precise, reproducible language. Avoid declaring an incident confirmed solely from a single alert. Preserve original timestamps and timezone context, minimize sensitive data in screenshots, and ensure evidence is stored only in an appropriate lab location.

Lab data only

Use authorized test systems and sanitized examples. Never publish real credentials, personal data, tokens, or unredacted sensitive logs in a public repository.
