01 · Overview

Architecture at a glance

Design & components

The lab uses virtual machines to create a controlled environment for endpoint monitoring, log collection, alert review, and authorized security testing. The diagram is intended to communicate the logical roles; confirm that it matches the network adapters and services actually configured on your VMs.

04 · Monitoring

Wazuh server and agent connectivity

Endpoint telemetry

Use the Wazuh dashboard screenshot to show enrolled agent status, and include only the endpoints that are actually installed and connected. Do not imply an agent is connected based only on the VM being present in VirtualBox.

05 · Event flow

From endpoint to investigation

Conceptual workflow

The intended monitoring flow is endpoint event generation, agent collection, central analysis, and analyst review. Actual event coverage depends on agent configuration, enabled log sources, and the rules deployed.

1. GenerateEndpoint activity
2. CollectWazuh agent
3. AnalyzeWazuh server
4. AlertRules & detections
5. InvestigateAnalyst review

For each validation exercise, record the test time, endpoint, relevant event or alert identifiers, observed result, and any limitations. Link the detailed evidence from the log-analysis, detection-rules, and incident-response sections of the repository.

06 · Safety & documentation

Keep the lab controlled

Lab boundaries
  • Use Kali and Metasploitable only against systems and networks you own or are explicitly authorized to test.
  • Keep Metasploitable 2 isolated from public, production, and other untrusted networks.
  • Do not publish passwords, private keys, tokens, or sensitive personal/network information in screenshots.
  • Update screenshots and descriptions when VM names, adapter modes, or deployment status change.
  • Clearly distinguish planned components from components that are installed and verified.
Project documentation: This page describes the lab based on the listed components and intended evidence. Keep the wording aligned with your actual setup and current screenshots.
