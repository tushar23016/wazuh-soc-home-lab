Custom Wazuh Rules

Example XML rule structure for local detection engineering.

View XML File ↗
⌘

Example Custom Detection Rule

XML · Wazuh Local Rules 
<!-- Example: Detect repeated SSH authentication failures -->

<group name="local,authentication,sshd,">

    <rule id="100100" level="10" frequency="5" timeframe="120">

        <if_matched_sid>5710</if_matched_sid>

        <same_source_ip />

        <description>
            Multiple SSH authentication failures from
            the same source IP address.
        </description>

        <mitre>
            <id>T1110</id>
        </mitre>

    </rule>

</group>
Example only. Verify the parent rule ID, event decoder, and rule compatibility against the installed Wazuh version and actual lab events before deployment. Custom rules belong in the Wazuh local rules configuration.
